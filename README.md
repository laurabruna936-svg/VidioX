# VidioX — Beta 0.1

Primeiro protótipo Android do editor.

## Incluído
- Tela inicial
- Novo projeto
- Seleção de vídeo da galeria
- Tela de edição
- Timeline visual
- Ferramentas: cortar, texto, áudio, efeitos e velocidade
- Botão de exportação e estrutura preparada para Media3 Transformer

## Próxima etapa
Implementar o corte real, preview com ExoPlayer, áudio, texto sobre o vídeo e exportação MP4 real.

## Como compilar
Abra a pasta no Android Studio com suporte a Gradle/Kotlin e execute o módulo `app`.
